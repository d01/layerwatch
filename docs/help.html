Layerwatch

Help

Layerwatch talks to your printer directly over your own network. These are the settings it needs on the printer, and what to check when something doesn't work.

Setting up the printer

  1. On the printer's screen, open its network settings: Settings → Network on the X1 and H2 series, Settings → WLAN on the P1 and A1 series.
  2. Turn on LAN Only Mode. This disconnects the printer from Bambu's cloud, so Bambu Handy and cloud printing from Bambu Studio stop working while it's on. Bambu Studio can still print to it over the network.
  3. Turn on Developer Mode. Recent firmware needs it before any app other than Bambu's own can connect and send commands.
  4. On the X1 and H2 series, turn on LAN Only Liveview to see the camera.
  5. Write down the IP address and the 8-character access code shown on that screen, and enter them in Layerwatch.

Tip: give the printer a fixed address (a DHCP reservation in your router), so it keeps the same IP address after a restart.

Connection problems

“The printer rejected that access code”

Check the code on the printer's network screen. It changes whenever it's regenerated there. Also check that LAN Only Mode and Developer Mode are both on. To enter a new code later, use Change access code in the ⋮ menu.

“Couldn't reach” the printer

  • Check the IP address against the printer's network screen.
  • Your phone has to be on the same network as the printer, or connected to it through a VPN. Mobile data on its own won't work.
  • Guest WiFi networks and some mesh systems keep devices apart. Try the main network.
  • If your network keeps devices apart (separate networks, VLANs or a firewall), make sure your phone can reach the printer on TCP ports 8883 (status and controls), 990 (files and timelapses), and either 322 (camera on the X1, P2S, H2 and X2 series) or 6000 (camera on the P1 and A1 series).

“Didn't present a Bambu printer certificate”

Something other than a Bambu printer answered at that address, usually because the printer's IP address has changed. Check it on the printer's screen.

The connection keeps dropping

Printer WiFi is often weak, especially with the printer inside an enclosure. Layerwatch reconnects on its own and keeps the camera running through short drops. A stronger WiFi signal at the printer helps the most, for example an access point closer to it.

Features

The camera says “LAN Only Liveview is off”

Turn on LAN Only Liveview in the printer's network settings (X1 and H2 series).

Controls are greyed out

The printer only accepts pause, stop, speed, light, skip and drying commands with Developer Mode on. Monitoring works either way.

“Dry filament” isn't offered or can't start

Drying needs an AMS 2 Pro or AMS HT with its power adapter connected, and the printer idle: the button is hidden during a print. Unload filament fed through the AMS outlet first. Filament can stay in the feeders, but not above its heat-distortion temperature: pull it back out, or lower the temperature. To rotate the spools while drying, pull the filament out of the feeders.

Skipping an object isn't offered

Skipping needs firmware that supports it, and a plate sliced with Exclude objects (label objects) turned on in Bambu Studio or OrcaSlicer. It works for up to 64 objects, once the print has started. To skip the last object left, stop the print instead.

No alerts while the phone is locked

Check that Background watching is on in the ⋮ menu, and that notifications are allowed for Layerwatch. Some phones also stop background apps to save battery. If alerts still don't arrive, set Layerwatch's battery use to Unrestricted in Android's app settings.
